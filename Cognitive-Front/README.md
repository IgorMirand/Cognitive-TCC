# Cognitive Mobile 📱

Aplicativo mobile da plataforma Cognitive desenvolvido com Kivy e KivyMD.

---

# 📌 Sobre

O aplicativo permite que pacientes realizem registros emocionais e acompanhem sua evolução terapêutica de forma simples e intuitiva.

---

# 🚀 Funcionalidades

- Login e autenticação
- Diário emocional
- Registro de humor
- Registro de atividades
- Histórico pessoal
- Comunicação com API REST

---

# 🛠 Tecnologias

- Python
- Kivy
- KivyMD
- Requests

---

# ⚙️ Instalação

## Instalar dependências

```bash
pip install -r requirements.txt
```

---

# ▶️ Executar Aplicação

```bash
python main.py
```

---

# 🔗 Integração com API

Configure a URL da API:

```python
BASE_URL = "https://api-tcc-cognitive.vercel.app/"
```
